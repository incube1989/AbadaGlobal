For every logged in user there is a button on calendar page "create new event"

On click:
- new page with event fields
- can edit those fields
- in the end "cancel", "publish event", "save as draft". Save as draft is disabled for now.


Edit event:
If user is owner of event OR user is moderator OR user is admin he can edit event:
- on event popup there appears button "edit event"
- on event page for those users there is a button "edit event"
