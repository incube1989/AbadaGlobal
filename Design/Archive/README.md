# Archive

Contains documents that have been **merged into the wiki** and moved out of
[`../Increment/`](../Increment/).

## Rules

- Files land here **only after** a successful, approved merge.
- This folder is the chronological record of what has been absorbed into the
  wiki. The wiki itself ([`../wiki/`](../wiki/)) is the live knowledge; here
  you can see what it was built from, in order.
- Files here are read-only references — do not re-merge them. If new
  information arrives that relates to an archived document, put it in
  [`../Increment/`](../Increment/) as a new file.
