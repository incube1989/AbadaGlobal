Vision of project: It is a site with backend for sport school of Capoeira in Russia for coaches.

Main features:
- calendar of events with ability to create and edit events
- login, admin user, moderator user, simple user
- notifications for each user
- data base of video, with manualy setted access
- main page with information about school and upcoming events
- all pages by default are accessible only to logged in users
- 3 languages - main russian, english, portuguese
- site is made for both desktop and mobile
- all pages have navigation bar


For MVP we are building only login with hardcoded users, calendar of events for hardcoded set of events, event page, navigation bar. User data and event date should be stored on backend side.
