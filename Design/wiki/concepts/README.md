# Concepts

Pages for **ideas, decisions, and syntheses**: decisions, patterns, and
specifications worth filing back into the wiki.

## Conventions

- One page per concept; use a descriptive slug (e.g. `rights-model.md`).
- YAML frontmatter: `title`, `tags` (include `concept`), `created`, `updated`,
  `sources`.
- Link related entities and sources.
- Concept pages are updated when new sources arrive (never removed).
