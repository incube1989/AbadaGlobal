# Concepts

Pages for **ideas, decisions, and syntheses**: ADRs, comparisons, patterns,
analyses, and anything valuable enough to file back into the wiki.

## Conventions

- One page per concept; use a descriptive slug (e.g. `adr-0001-monorepo.md`).
- YAML frontmatter: `title`, `tags` (include `concept`), `created`, `updated`.
- For decisions, follow a lightweight ADR format:
  - **Context** — why this decision matters
  - **Decision** — what was chosen
  - **Consequences** — trade-offs, follow-ups
  - **References** — linked sources/entities
- Link related entities and sources.
