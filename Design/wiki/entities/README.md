# Entities

Pages for **real things**: systems, components, people, organizations, domains.

## Conventions

- One page per entity, file name = entity slug (e.g. `frontend.md`).
- YAML frontmatter: `title`, `tags` (include `entity`), `created`, `updated`,
  `sources` (number of sources that reference this entity).
- Keep a short description, key facts, relationships (link to other pages),
  and open questions.
