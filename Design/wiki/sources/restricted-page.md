# Source — Restricted Page Increment Doc

Summary of [`Design/Increment/RestrictedPage.md`](../../Increment/RestrictedPage.md)
(archived as `Design/Archive/RestrictedPage.md`).

Shown when a user tries to open a page that is not available to them due to
view rights:

- Unlogged user: "Sorry, you do not have permission to view this page. Please log in to continue."
- Logged user: "Sorry, you do not have permission to view this page. Contact Admin for details."
