# Sources

One summary page per **ingested source document** from
[`../../raw/`](../../raw/).

## Conventions

- File name mirrors the source, e.g. `meeting-2026-10-07.md`.
- YAML frontmatter: `title`, `tags` (include `source`), `date`, `source_path`
  (relative link to the raw file), `status` (`draft`/`ingested`).
- Body structure:
  - **Summary** — key takeaways in a few paragraphs
  - **Key points** — bullet list of the most important facts
  - **Connections** — links to affected entity/concept pages
  - **Contradictions / notes** — anything that conflicts with existing pages
- Ingestion always updates [[index|the index]] and appends to
  [[log|the log]].
